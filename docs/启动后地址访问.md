浏览器直接访问 http://localhost:8013/（api 模块端口 8013，前端就是它自带的 Thymeleaf 页面）。

页面入口：

| 页面             | 地址                                           |
| ---------------- | ---------------------------------------------- |
| 商品列表（首页） | http://localhost:8013/ 或 /product/list        |
| 登录             | http://localhost:8013/login                    |
| 注册             | http://localhost:8013/register                 |
| 商品详情         | http://localhost:8013/product/detail?id=商品ID |
| 排队页           | 详情页点秒杀自动跳 /queue                      |
| 订单列表         | http://localhost:8013/order/list               |
| 支付页           | http://localhost:8013/payment                  |


完整体验链路： 注册 → 登录 → 商品列表 → 点商品进详情 → 填验证码秒杀 → 排队页轮询结果 → 订单列表查看订单 → 支付。

两个前提提醒：

商品列表/详情是查 ES 的 —— 你还没建 seckill-product-es-index-v1 索引并灌数据的话，列表和详情会是空的，按我上一条消息的建索引语句先执行一遍；
下单是 MQ 异步的 —— 确保 seckill-job 模块也在跑，否则秒杀请求提交了但没人建订单。
